# Mr.Clipy

Screen recording, Instant Replay and a multi-track editor for Windows.

## Download

**[MrClipy-Setup-0.2.0.exe](https://github.com/justpainful/MrClipy/releases/latest/download/MrClipy-Setup-0.2.0.exe)** (143 MB, Windows 10 or 11, 64-bit)

1. Open the file and follow the steps. No administrator rights are needed.
2. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway** (the installer isn't code-signed).
3. Open Mr.Clipy from the Start menu or the desktop.

To remove it: Settings, Apps, Mr.Clipy, Uninstall. Your recordings (Videos\MrClipy) are kept.

## Notes

- The interface needs Microsoft Edge WebView2, which is part of Windows 11 and most Windows 10 PCs. The installer offers its download page if it's missing.
- Transcription works once a local Whisper model is installed; everything else works out of the box.
- Includes FFmpeg (GPL v3, build by gyan.dev). Its license is in `tools\FFmpeg-LICENSE.txt` in the install folder; source: https://ffmpeg.org/download.html and https://www.gyan.dev/ffmpeg/builds/
